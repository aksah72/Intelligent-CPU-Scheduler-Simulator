# ⚙️ CPU Scheduling Simulator

An interactive and visual CPU Scheduling Simulator supporting **FCFS**, **SJF**, **Priority**, and **Round Robin** algorithms. Built with pure HTML, CSS, and JavaScript, this tool helps users understand how different CPU scheduling techniques work through **dynamic Gantt charts**, **statistics**, and **step-by-step visualizations**.

## 📌 Features

- 🖥️ Support for 4 algorithms:
  - **FCFS** (First Come First Serve)
  - **SJF** (Shortest Job First)
  - **Priority Scheduling**
  - **Round Robin**
- 📊 Gantt Chart Visualization with animated playback
- 📈 Real-time calculation of:
  - Waiting Time (WT)
  - Turnaround Time (TAT)
  - Completion Time (CT)
  - CPU Utilization
- 🌗 Light/Dark theme toggle
- 🧮 Interactive metrics and formula explanations
- 🧩 Add, edit, or delete custom process inputs dynamically
